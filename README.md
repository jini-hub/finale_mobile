# Finale Mobile v2

상속 절차를 한 곳에서 정리하는 모바일 우선 정적 SPA 데모입니다.

## 포함 기능
- 상속 사건 생성/진행률
- 사망자 정보 및 승인·포기 관련 기한 계산
- 상속인/가족관계 입력
- 상속재산/채무 목록
- 단순승인/한정승인/상속포기 판단 보조
- 상속세 간이 계산기
- 상속재산분할 작업공간
- 유언/유류분 안내
- 서류 체크리스트
- 전문가 상담용 사건 요약
- JSON 백업
- 모바일 하단 네비게이션 + 사이드 메뉴
- localStorage 기반 저장

## 법률 안전 설계
이 프로젝트는 법률·세무 자문을 제공하거나 신고를 자동 제출하지 않습니다.
2026년 3월 17일 시행 민법을 기준으로 유류분 권리자에서 형제자매가 제외된 점을 반영했습니다.
상속 승인·포기 기간은 원칙적으로 상속개시 있음을 안 날부터 3개월이라는 점을 반영했지만,
앱이 사망일만으로 기산점을 확정하지 않도록 문구를 넣었습니다.
상속세 신고기한은 국세청의 일반 6개월 / 일부 9개월 기준을 안내합니다.

## 실행
index.html을 정적 호스팅(GitHub Pages 등)에 올리면 실행됩니다.

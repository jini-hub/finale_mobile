# Finale Mobile v3 — 상속 사건 관리 플랫폼

## 목적
상속인이 사망 직후 해야 할 일부터 상속인 확정, 재산·채무 전수조사, 승인/포기, 상속세, 유언/유류분, 상속재산분할, 서류, 전문가 검토까지 하나의 사건파일에서 관리할 수 있도록 구성한 모바일 우선 정적 SPA입니다.

## 주요 기능
- 피상속인/사망일/상속개시 인지일 관리
- 상속인 및 가족관계/미성년/대습 가능성 기록
- 재산·채무 전수조사 및 확인상태 관리
- 단순승인·한정승인·상속포기 정보와 특수상황 플래그
- 상속세 신고기한 및 간이 검토 계산
- 유언·유류분(2026-03-17 시행 민법 기준) 관리
- 상속재산분할안 및 명의정리 체크
- 서류센터/기한/할일 관리
- 상담용 사건요약 생성 및 JSON 백업
- 공식기관 출처 링크

## 법률 안전 설계
이 프로젝트는 “모든 법률행위를 자동 처리”하는 앱이 아니라, 현재 대한민국 기준의 법률·행정정보를 구조화하고 누락 가능성을 줄이는 사건관리 도구를 목표로 합니다. 실제 법원 심판청구, 상속세 신고, 상속등기, 소송·분쟁 대응 등은 기관의 최신 공식서식 및 자격 있는 전문가 확인이 필요합니다.

## 중요한 법률 기준
- 민법 제1000조: 법정상속 순위
- 민법 제1019조: 승인·포기 기간(원칙적으로 상속개시 있음을 안 날부터 3개월)
- 민법 제1112조: 2026-03-17 시행 유류분 규정
- 국세청: 일반적인 상속세 신고기한 6개월, 일정한 외국주소 사유 등 9개월

## 실행
index.html을 브라우저로 열어 실행할 수 있습니다. 서버 없이 localStorage 기반으로 동작합니다.

## 상용화 전 필수 추가 작업
1. 서버/DB/로그인/권한/암호화
2. 개인정보보호 및 민감정보 최소수집 설계
3. 기관 API와 전자민원 연계에 대한 자격/법적 검토
4. 변호사·법무사·세무사 연결 서비스의 관련 법령 검토
5. 법령/예규/판례 업데이트 체계
6. 실제 제출용 서식의 기관 최신 양식 검수
7. 감사로그·접근권한·문서보존·파기정책
